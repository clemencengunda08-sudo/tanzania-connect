# Phrasebook & Apps

A basic Swahili (Kiswahili) vocabulary makes Tanzania come alive. Most Tanzanians are patient and delighted when visitors make the effort — even a single "asante" (thank you) opens smiles. Swahili is a Bantu language with regular grammar: most verb tenses are formed by adding prefixes. Pronunciation is straightforward: every vowel is pronounced, and "r" is lightly rolled.

## Key Facts

- **Swahili (Kiswahili)** is spoken as L1 or L2 by ~95% of Tanzanians and is the national language. English is widely spoken in tourist areas, but rural Tanzania is Swahili-only.
- **Pronunciation tip**: every vowel is pure — a = ah, e = eh, i = ee, o = oh, u = oo. Stress falls on the second-to-last syllable.
- **"I" is "mimi"**, "you (singular)" is "wewe", "we" is "sisi" (cute: ends in -sisi like the country).
- **Greeting etiquette**: start with habari, then follow up with habari za kazi (work), habari za familia (family), habari za safari (journey). Take time.

## Greetings & Basics

| Swahili | English |
|---|---|
| Habari! | Hello! / What's the news? |
| Nzuri, asante | Fine, thank you |
| Mambo! | Hey! (very casual) |
| Poa | Cool / great |
| Vipi? | How's it going? |
| Salaam aleikum | Peace be with you (Muslim greeting) |
| Aleikum salaam | And with you (response) |
| Shikamoo | I hold your feet (respectful greeting to elders) |
| Marahaba | Response to shikamoo |
| Asante (sana) | Thank you (very much) |
| Karibu | Welcome / You're welcome |
| Tafadhali | Please |
| Ndiyo | Yes |
| Hapana | No |
| Pole | Sorry (also "sorry to hear") |
| Samahani | Excuse me / sorry |
| Kwaheri | Goodbye |
| Tutaonana | See you later |

## Useful Phrases

| Swahili | English |
|---|---|
| Jina langu ni ... | My name is ... |
| Unaitwa nani? | What's your name? |
| Unatoka wapi? | Where are you from? |
| Ninatoka ... | I'm from ... |
| Naweza kusaidika? | Can I help? |
| Tafadhali, naomba ... | Please, I would like ... |
| Unazungumza Kiingereza? | Do you speak English? |
| Sijaelewa | I don't understand |
| Tafadhali, sema pole pole | Please speak slowly |
| Bei ngapi? | How much? |
| Ni ghali sana! | It's very expensive! |
| Ninataka kufanya mazungumzo | I want to negotiate |
| Njoo! / Nendeni! | Come! (sing/pl) / Go! (pl) |
| Twende! | Let's go! |
| Tuko wapi? | Where are we? |
| Nipe maji tafadhali | Give me water please |
| Naomba kuja/msaada wako | I need your help |
| Nimechoka | I'm tired |
| Nimeona / nimefika | I've seen / I've arrived |

## Numbers

- 1 moja, 2 mbili, 3 tatu, 4 nne, 5 tano, 6 sita, 7 saba, 8 nane, 9 tisa, 10 kumi
- 11 kumi na moja, 20 ishirini, 30 thelathini, 40 arobaini, 50 hamsini, 60 sitini, 70 sabini, 80 themanini, 90 tisini
- 100 mia, 1,000 elfu, 10,000 elfu kumi, 1,000,000 milioni
- Money: shilingi (TZS), senti (cents)

## Days, Months, Time

- siku (day), wiki (week), mwezi (month), mwaka (year)
- weekday: Jumatatu (Mon), Jumanne (Tue), Jumatano (Wed), Alhamisi (Thu), Ijumaa (Fri), Jumamosi (Sat), Jumapili (Sun)
- months: Januari–Disemba (Jan–Dec)
- time: saa = hour; leo = today; kesho = tomorrow; jana = yesterday; asubuhi = morning; mchana = afternoon; jioni = evening; usiku = night
- saa ngapi? = what time is it?
